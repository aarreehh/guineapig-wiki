# Security Policy

## Supported Versions

We currently provide security updates for the latest version of the project.

| Version | Supported |
|---|---|
| Latest | ✅ |
| Older versions | ❌ |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately.

- **Do not** open a public GitHub issue.
- Send details to: **security@guineapigwiki.org**
- Include steps to reproduce, impact, and any suggested remediation if available.

What to expect after reporting:

1. You will receive an acknowledgement within **72 hours**.
2. We will investigate and assess severity.
3. We will work on a fix and coordinate a responsible disclosure timeline.
4. You will be credited for your report (if you want) once the issue is resolved.

Thank you for helping keep Guinea Pig Wiki and our users safe.
